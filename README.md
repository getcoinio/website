# Coinio Website

![Coinio: every subscription, one calm page](public/assets/og.png)

Marketing website and live browser demo for [Coinio](https://github.com/getcoinio/coinio), served at [getcoinio.me](https://getcoinio.me) in 8 languages.

Built with Astro 5 and deployed to Cloudflare Pages (`coinio-site`).

```sh
pnpm install
pnpm dev      # http://localhost:4663
pnpm build    # static output in dist/
```
